# Marcelo Ojeda — Software Architecture

Sitio profesional orientado a mostrar experiencia real en arquitectura de software mediante casos comprensibles para perfiles de negocio y técnicos.

## Objetivo

Este sitio no será un CV trasladado a la web. Busca demostrar arquitectura de software y diseño de sistemas, integración y modernización de plataformas enterprise, construcción de productos SaaS y capacidad de conectar decisiones técnicas con problemas de negocio.

## Principios

Cada caso seguirá **Contexto → problema → restricciones → decisiones → arquitectura → resultado**.

La información visual tendrá explicación textual equivalente para accesibilidad, SEO y comprensión automatizada. No se publicará código propietario, secretos ni información confidencial.

## Arquitectura inicial

- Home — posicionamiento y propuesta profesional.
- Architecture Stories — casos explicados visualmente.
- Experience — trayectoria seleccionada.
- About — perfil, enfoque y formación.
- Contact — canales profesionales.

## Audiencias

El contenido tendrá tres profundidades: lectura de 30 segundos para problema/rol/impacto; 3 minutos para arquitectura y decisiones; 10 minutos para patrones, trade-offs y detalle técnico.

## Descubrimiento

La implementación considerará HTML semántico, rendimiento, accesibilidad, metadata, canonical URLs, Open Graph, sitemap, robots.txt y Schema.org/JSON-LD. La estructura permitirá español e inglés.
